# Cock v Cats

Ein Hahn. Neun Katzen. Ein Hof. Ein Prügelspiel im Stil von Street Fighter mit Touch-Steuerung,
Bosskämpfen, Upgrades, Endlos-Modus, Boss-Marathon und Training.

## Auf GitHub Pages veröffentlichen

1. Im Repository auf **Settings → Pages** gehen.
2. Bei **Source** „Deploy from a branch“ wählen, Branch **main** und Ordner **/ (root)**, dann **Save**.
3. Nach ein bis zwei Minuten läuft das Spiel unter `https://<dein-name>.github.io/cvsc/`.

## Auf den iPhone-Homescreen legen

1. Die Pages-Adresse in **Safari** öffnen.
2. Auf das Teilen-Symbol tippen und **Zum Home-Bildschirm** wählen.
3. Das Spiel startet danach im Vollbild ohne Browserleiste und funktioniert auch offline.

Spielstand, Upgrades und Kostüme werden auf dem Gerät gespeichert.

## Steuerung

- **◀ ▶** laufen, zweimal tippen = Sprint, nach hinten halten = blocken
- **▲** springen, **▼** ducken
- **PICK, PICK, KRALLE** Kombo, **PICK + KRALLE** nah dran = Wurf
- **FEDER** Feuerfeder, **▶ + FEDER** Ansturm, **▼ + FEDER** Flügelwirbel
- **KIKERIKI** Superangriff, wenn die Leiste voll ist

Tastatur: Pfeile oder WASD, J Pick, K Kralle, L Feder, I Kikeriki, P Pause.

Die Figuren und Arenen wurden mit KI-Bildmodellen auf Hugging Face erzeugt, ausgeschnitten und im Spiel animiert.
Musik und Soundeffekte entstehen live im Browser.
